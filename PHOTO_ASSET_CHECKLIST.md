All site photographs open in a full-screen viewer when clicked. Close it using the close button, by clicking the dark backdrop, or by pressing Escape. On non-doctor photos, the local file is used automatically as soon as it exists; a temporary stock image is shown only while the local file is missing. Doctor portraits intentionally do not fall back to stock photos.

Only use original, approved hospital/doctor photographs. Obtain parent/guardian consent and hospital authorization before publishing identifiable patient or child photographs.
